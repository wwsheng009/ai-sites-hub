## 需求概要（一句话）

把散落各处的 AI 中转站点（sub2api / new-api）集中到一个平台里：
**登记站点 → 自动识别站点类型 → 自动登录 → 定时签到 → 集中查询 key/分组/额度 → 同步返利并支持阈值自动划转（FR-10，方案 B）→ 通过 Web / API / cmd 三种入口统一操作。**
